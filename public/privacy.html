プライバシーポリシー

制定日・最終更新日: 2026年11月25日

yude（以下「運営者」といいます）は、運営者が提供する Google Apps Script アプリケーション、Google Workspace アドオン、Web サービス、その他各種ツール（以下総称して「本サービス」といいます）におけるユーザーデータの取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

1. アクセス・収集する情報

本サービスは、ユーザーが明示的に OAuth 等を通じて承認した範囲（スコープ）に限り、以下の Google ユーザーデータその他の情報にアクセスまたは取得する場合があります。

  • Google アカウントの基本情報（メールアドレス、表示名等、各サービスの動作に必要な範囲）
  • Google Drive、Google スプレッドシート、Google ドキュメント、Gmail、Google カレンダー等のデータ（各アプリケーションにおいてユーザーが認可した権限の範囲内）
  • エラー解析や動作維持のための最小限の実行ログ

2. 情報の利用目的

取得またはアクセスした情報は、以下の目的にのみ利用します。

  • ユーザーが認可した本サービスの機能を提供・実行するため
  • 本サービスの不具合調査、保守および品質向上のため
  • ユーザーからのお問い合わせに対応するため

取得した情報を広告配信、マーケティング、プロファイリング、または第三者への販売のために利用することはありません。

3. Google API サービス ユーザーデータポリシーへの準拠

本サービスによる Google API から受け取った情報の使用および他のアプリへの転送は、制限付き使用（Limited Use）の要件を含め、 Google API Services User Data Policy に準拠します。

また、Google Workspace API を通じて取得したユーザーデータを、汎用的な AI（人工知能）または機械学習（ML）モデルの開発、改善、学習のために使用することはありません。

4. データの保存・保持期間・セキュリティ

  • 多くの Google Apps Script ツールでは、データは実行時に一時的に処理されるか、ユーザー自身の Google 環境（Google Drive、スプレッドシート、スクリプトプロパティ等）内のみで扱われます。
  • 運営者の管理する環境でデータを保持する必要がある場合は、機能提供に必要な最小限の期間のみ保持し、不要となったデータは速やかに削除します。
  • 通信の暗号化（HTTPS/TLS）、最小権限のスコープ設計、適切なアクセス制御など、合理的な安全管理措置を講じます。

5. 第三者への提供

運営者は、次の場合を除き、ユーザーデータを第三者へ提供・開示しません。

  • ユーザー本人の明示的な同意がある場合
  • ユーザーが明示的に設定した外部サービス連携等、本サービスの核となる機能の実行に不可欠な場合
  • 法令に基づき開示が求められた場合

6. アクセス権限の取り消しおよびデータ削除

ユーザーはいつでも Google アカウントの権限管理ページ から本サービスへのアクセス権限を取り消すことができます。

運営者が保持しているデータの確認または削除を希望される場合は、下記お問い合わせ先までご連絡ください。合理的な期間内に対応いたします。

7. 本ポリシーの変更

運営者は、法令の変更や本サービスの内容変更等に応じて、本ポリシーを改定することがあります。改定後のポリシーは、本ページに掲載された時点で効力を生じます。

8. お問い合わせ

本ポリシーおよびユーザーデータの取扱いに関するお問い合わせは、以下までご連絡ください。

Privacy Policy

Effective / Last Updated: November 25, 2026

This Privacy Policy explains how yude ("Operator", "we", or "us") accesses, uses, stores, and protects user data in connection with Google Apps Script applications, Google Workspace add-ons, web services, and other scripts or tools operated by yude (collectively, the "Services").

1. Information We Access and Collect

Depending on the specific Service and only within the OAuth scopes explicitly authorized by you, the Services may access or collect:

  • Basic Google account information (such as email address or profile information, only when required by the Service).
  • Google user data from Google Workspace services (such as Google Drive, Sheets, Docs, Gmail, or Calendar) strictly limited to the scopes you approve.
  • Minimal technical or execution logs necessary for troubleshooting and maintaining service reliability.

2. How We Use Information

We use accessed or collected data solely to:

  • Provide, operate, and execute the user-facing features of the Service you authorized.
  • Diagnose errors, maintain security, and improve service reliability.
  • Respond to user inquiries and support requests.

We do not use Google user data for advertising, marketing, user profiling, or selling data to third parties.

3. Compliance with Google API Services User Data Policy

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Data obtained through Google Workspace APIs is not used to develop, improve, or train generalized AI and/or machine learning (ML) models.

4. Data Storage, Retention, and Security

  • In most Google Apps Script tools, data is processed transiently during script execution or stored solely within your own Google environment (e.g., your Google Drive, Sheets, or Script Properties).
  • Where external storage is required to provide a feature, data is retained only for as long as necessary for that purpose and deleted when no longer needed.
  • We implement reasonable technical and organizational measures—including HTTPS/TLS encryption, least-privilege OAuth scopes, and access controls—to protect user data.

5. Data Sharing and Disclosure

We do not sell, rent, or share Google user data with third parties, except:

  • With your explicit consent.
  • When strictly necessary to perform core functionality explicitly configured by you (such as sending data to an external webhook or API you specified).
  • When required to comply with applicable laws, regulations, or valid legal processes.

6. Revoking Access and Requesting Data Deletion

You may revoke any Service's access to your Google account at any time via your Google Account Permissions page.

To request access to or deletion of any data retained by us, please contact us using the details below. We will respond within a reasonable timeframe.

7. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any changes will take effect upon posting the revised version on this page with an updated revision date.

8. Contact

If you have any questions regarding this Privacy Policy or our data practices, please contact:
